A real-time system metrics dashboard built with Angular and Node.js. 
Displays live CPU, memory, and network usage data with severity filtering, 
sorting, and live scrolling charts

To start the project clone this project into your IDE using git clone and on the root of this project use the commands npm run setup and npm start
then go to http://localhost:4200 to view the webpage, you can view this on your phone by going to http://(IPv4):4200

Requirements
- Node.js v20 or higher
